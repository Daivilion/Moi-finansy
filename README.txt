МОИ ФИНАНСЫ — PWA

Что умеет:
- старт с августа 2026 года без конечного ограничения по годам;
- зарплата / доход по каждому месяцу;
- обязательные платежи: ежемесячные, ежегодные и разовые;
- накопления как процент от остатка после обязательных платежей;
- планируемые расходы и свободный остаток;
- прогноз на 12 месяцев;
- локальное хранение данных в Safari;
- экспорт / импорт резервной копии JSON;
- офлайн-работа после первой загрузки.

Для установки на iPhone приложение нужно опубликовать по HTTPS.
После публикации открыть адрес в Safari → Поделиться → На экран Домой → включить «Открывать как веб-приложение» → Добавить.
